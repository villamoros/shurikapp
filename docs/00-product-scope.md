# SHURIKAPP v1 - Product Scope

## Objective

Build a multi-tenant platform for early-career professionals and freelancers with a shared foundation, a work OS, and an initial marketplace.

## Core product pillars

### Foundation

- Authentication
- Organizations
- Teams
- Roles
- Permissions
- Notifications
- Subscriptions
- Audit trail

### Work OS

- Projects
- Tasks
- Time tracker
- Calendar
- Dashboard

### Methodologies

- Scrum
- Kanban
- Scrumban
- Shape Up
- XP
- Waterfall
- Lean

### Marketplace initial version

- Professional profiles
- Job posting
- Freelance project posting
- Apply to jobs
- Apply to freelance projects

## MVP segments

### Career Free

For students and junior professionals.

Includes:

- Professional profile
- Digital CV
- Job applications
- Work history
- Personal dashboard
- Personal time tracker
- 7 personal projects
- 1 project per methodology

### Freelancer Free

Includes:

- Professional profile
- Portfolio
- Marketplace access
- Apply to projects
- 7 active projects
- 1 project per methodology
- Time tracker

## Product assumptions

- Multi-tenant from day one.
- Organizations and teams exist in the core domain, even if some free users start as individual tenants.
- Methodologies are configuration-driven, not separate products.
- The first MVP focuses on functional core flows, not an advanced ATS.
